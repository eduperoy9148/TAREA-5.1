Página Web Básica

Este proyecto fue creado como parte de mi aprendizaje en desarrollo web. Utilicé HTML para organizar el contenido de la página mediante títulos, párrafos, enlaces y diferentes etiquetas.

Con este proyecto aprendí la importancia de mantener una estructura organizada para que el contenido de una página web sea fácil de comprender y modificar.
